# X10THINK Daily Research public site

This static site renders only the privacy-safe JSON generated by
tools/export_public_daily_research.py. It never reads the research vault in the
browser and it does not call the authenticated Research OS API.

## Local preview

1. From the project root, run the project-root assertion through PowerShell.
2. Export the current public feed with the Python exporter.
3. Serve this directory with a local Python static server.
4. Open http://127.0.0.1:4174.

The generated data/public-daily-research.json file is intentionally ignored by
Git. A deployment workflow should publish that generated file alongside this
static directory only after the normal research review has completed.

Public publication history starts with the 2026-09-01 issue. The exporter and
the browser both exclude older local recommendation records from the public
card and archive.

The normal tools/run_daily_research_operations.ps1 runner updates the generated
feed after its recommendation preview step. Use
-SkipPublicDailyResearchExport only when that local export needs to be skipped
for maintenance; it does not publish to WordPress or any other external host.

## Public hosting boundary

This directory is deployed as a standalone static Vercel project. Its
.vercelignore file allowlists only the rendered HTML, CSS, JavaScript, favicon,
deployment configuration, and the already-sanitized public JSON feed. Publish
only after the normal research review; the public host must never receive the
parent repository, the authenticated API, or the research vault.

The active fallback address is https://x10think-daily-research.vercel.app.
The intended WordPress-connected address is
https://research.openheritagearchive.com. Keep the WordPress root site in place;
the only required DNS change is the documented `research` CNAME record.
