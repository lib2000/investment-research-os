# 수치 모델 공통 벤치마크·승격 기준

- 상태: 적용
- 대상: Kronos 및 향후 대체 금융 시계열 모델
- 목적: 단일 모델의 주장이나 한 종목 결과만으로 추천·자동매매 경로에 연결되지 않도록 공통 게이트를 고정한다.

## 공통 평가 계약

- 조정가격 여부와 corporate action 처리 상태를 기록한다.
- 필수 OHLCV 검증 후 시간 순서를 유지한 워크포워드만 사용한다.
- 마지막 종가 유지 기준선과 로그수익률 드리프트 기준선을 함께 계산한다.
- 종목별·기간별 MAE, 방향성 정확도, 보정률, 엄격 실패율을 저장한다.
- 수수료·슬리피지·시장충격이 없는 결과는 매매수익률로 해석하지 않는다.

## 승격 게이트

현재 기본값은 다음과 같다.

- 기준선 대비 평균 개선률: `>= 0%`
- 엄격 출력 실패: `0건`
- 출력 보정률: `0%`
- 다종목·다기간 평가 완료
- 사람의 데이터·리스크 검토 완료

하나라도 충족하지 못하면 판정은 `hold_research_only`이며 추천·텔레그램·주문 경로에 연결하지 않는다. 모든 모델은 처음부터 `research_only` 모드로 실행되고 자동 승격되지 않는다.

## 현재 Kronos 판정

- 조정가격 10종목 평가: 기준선 대비 평균 `-21.94%`
- 민감도 최적 조합: 기준선 대비 `-8.36%`
- 출력 보정: 다수 발생
- 판정: `hold_research_only`

## 대체 모델 비교 순서

1. 동일 데이터셋·동일 창·동일 기준선으로 실행
2. 모델별 결과를 위 지표로 정규화
3. 비용·슬리피지 포함 페이퍼 백테스트
4. 사람 검토 후 연구용 화면에만 제한 노출
5. 실거래 연결은 별도 설계와 명시적 승인 이후에만 검토
