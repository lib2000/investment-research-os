# 공개 IR/SEC 티커 인증 연속성

- 상태: 구현 완료
- 작성일: 2026-08-30
- 범위: 공개 SEC·회사 IR 원문이 포트폴리오 리서치 배치에서 안전하게 재사용되는 경로

## 목표

공식 공개 원문을 저장했더라도 티커 검증 메타데이터가 없어서 포트폴리오 근거에서 제외되는 문제를 없앤다.

## 결정

- 서버의 로컬 티커 레지스트리에서 `verified=true`와 정확한 `official_symbol`을 확인한 경우만 저장한다.
- HTTPS SEC EDGAR 또는 회사 IR 도메인·출처 유형이 확인된 문서만 자동 연결한다.
- 기존 문서는 `tools/backfill_public_ir_sec_ticker_verification.py --ticker <ticker> --write`로 manifest 메타데이터만 보강한다.
- 원문 파일, 포트폴리오 수량, 문서 커버리지, 사람 검토 게이트, 주문은 변경하지 않는다.

## 제외 범위

- 임의 웹 URL·미검증 티커·본문 품질 부족 자료를 공식 종목 근거로 승격하지 않는다.
- 기준 리포트, 매매 전략, 체크리스트 자동 완료를 하지 않는다.
- 외부 URL 재수집이나 모델 호출은 backfill 단계에서 수행하지 않는다.

## 검증

- 새 수집 문서가 검증 메타데이터를 저장하는지 테스트한다.
- 기존 문서 backfill은 공식 SEC URL만 바꾸고 비공식 URL은 보류하는지 테스트한다.
